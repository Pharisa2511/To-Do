# รายการสิ่งที่ต้องทำ (Todo TH)

React + Vite + Tailwind CSS + lucide-react

## เริ่มใช้งาน

```bash
npm install
npm run dev      # เปิดโหมดพัฒนา
npm run build    # สร้างไฟล์สำหรับ production ใน dist/
npm run preview  # ดูผลลัพธ์ที่ build แล้ว
```

ข้อมูลทั้งหมดอยู่ใน React state เท่านั้น (ไม่ใช้ localStorage) รีเฟรชหน้าแล้วข้อมูลจะรีเซ็ต
